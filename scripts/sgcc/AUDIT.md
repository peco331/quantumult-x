## 1. 业务机制与风险分析

网上国网 App 在用户进入「我的 / 积分签到」页面时，会发起带特定会话凭证及设备特征头的 POST 签到请求。其鉴权与签名机制包含：
- 请求头中的会话凭证 `t` 与用户标识 `userid`；
- 若干设备指纹及网关路由头（如 `device_token`, `appguid`, `wtoken`, `os`, `version` 等）；
- 请求体中的业务加密载荷 `data` 与密钥指纹 `skey`；
- 时间戳 `timestamp` 与基于国家商用密码国密 SM3 算法计算的签名：`sign = sm3(skey + data + timestamp)`。

由于服务端不校验动态验证码，仅对签名及凭据有效期做校验，因此通过拦截复用 `data`、`skey` 及 `t` 即可实现无人值守自动签到。但原版实现存在数项安全与风控隐患：
1. **宽泛拦截风险**：上游原版使用正则 `^https?:\/\/csc-service\.sgcc\.com\.cn:28630\/.+\/member\/`，该正则会匹配网上国网 App 会员中心下所有接口，导致其他常规浏览或敏感操作请求被不必要地送入脚本解析；
2. **凭据冗余泄露风险**：原版抓取脚本在 `WANT` 列表中收集了 `authorization` 等高危全局身份认证头。尽管签到接口实际上并不需要 `authorization`，但原版依然将其持久化存储；
3. **连续重试引发风控**：原版在网络或接口报错时默认以 3 秒间隔连续发起 3 次请求（MAX_RETRY = 3）。网上国网服务端在 Cookie 失效或风控拦截时统一返回模糊的“系统正忙”，短时间内连续重试非但无法解决凭据过期，反而极易触发 IP 或设备账号级别的频控惩罚；
4. **多平台 Env 垫片过重**：原版包含 100 余行兼容 Surge/Loon/Stash/Node 的 Env.min.js 垫片，逻辑复杂且对 Quantumult X 原生环境有不必要的代码膨胀。

## 2. 本地加固与对比矩阵

| 审计维度 | 上游原版实现 (cbb3c47) | 本地 QX 最小权限版 (scripts/sgcc/qx) | 加固收益 |
|---|---|---|---|
| **重写匹配路径** | 宽泛匹配 `/.+/member/` | 精准匹配 `/osg-omgmt1042/member/m1/0103514` | 规避非签到业务流量与敏感请求泄露，性能开销降到最低 |
| **请求头抓取范围** | 包含 `authorization` 等 18 项请求头 | 彻底移除 `authorization`，仅保留必需的 `t`、`userid` 及设备网关头 | 最小权限原则，降低凭据被盗用时的横向权限影响 |
| **重试策略** | 失败后间隔 3s 连续重试 3 次 | **严格单次请求（0 次重试）** | 遵守账号安全与反风控原则，防范接口频发异常导致封禁 |
| **数据存储** | 依赖 BoxJS / $persistentStore / $prefs | 原生绑定 Quantumult X `$prefs` 持久化存储 | 纯本地闭环，严禁网络外发 |
| **定时任务策略** | 默认 `enabled=true` | 默认 `enabled=false`，要求先手动测试验证 | 避免未就绪凭据产生静默失败与日志污染 |
| **运行运行时** | 携带沉重的多端 Env 兼容层 | 专为 Quantumult X 设计的原生精简执行体 | 结构透明，零第三方混淆依赖，便于审计 |

## 3. MITM 影响范围界定

- **解密域名**：`csc-service.sgcc.com.cn`
- **解密端口**：`28630`
- **说明**：网上国网 App 客户端内部采用双向或单向 TLS，在安装并信任 Quantumult X 本地根证书的前提下，仅对该指定网关进行流量解析。不得将主机名通配为 `*.sgcc.com.cn`，防止解密国网其它支付或电网调度敏感系统。

## 4. 账号安全与防风控说明

1. **Cookie 有效期**：根据实测基线，网上国网 App 的 `t` 会话凭证有效期通常在 4~5 天左右。当 `t` 或服务端会话失效时，签到接口会返回失败信息；
2. **失效处理流程**：当收到脚本推送的“⚠️ 网上国网签到未成功”通知时，切勿反复重试；只需在手机上启动网上国网 App，重新点击进入「我的 / 积分签到」页面，重写脚本会自动静默抓取最新凭据并更新本地存储；
3. **黑灰产防护**：本脚本只针对个人真实设备凭据做离线签到，不包含任何绕过验证码、虚假设备模拟或自动化打码逻辑。
